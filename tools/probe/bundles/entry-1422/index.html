entry-1422 — пробы для PS5 14.22 (WebKit entry)

Задача: за один заход определить, закрыт ли в 14.22 вход через реентерабельный Canvas2D getContext() (CVE-2026-43720 / WebKit bug 313175), и какой ветке Safari соответствует движок.

  1. p1 — canvas reentrancy oracle — главный ответ: FIXED / VULNERABLE / UNKNOWN. Запускать первым, он безопасный (не роняет процесс).
  2. p2 — engine fingerprint — ветка Safari (17.0–17.3 / ≥17.4 / ≥18.x), чтобы понять, ребейзила ли Sony движок.
  3. p3 — crash oracle — только если p1 = VULNERABLE. Требует ?armed=1; чтение freed-контекста может уронить WebProcess.

Результаты уходят на POST /beacon сервера стенда и дублируются на экране. Смотрите лог сервера: tools/probe/logs/beacons.jsonl и requests.jsonl.

python3 tools/probe/serve.py --root tools/probe/bundles/entry-1422 --port 8443
