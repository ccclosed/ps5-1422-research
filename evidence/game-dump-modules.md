# Системные модули в игровых дампах 14.2x-эпохи (sce_module/*.prx)

Статус: в работе. Каждое утверждение — с командой и её реальным выводом.

## 0. Постановка

Игровой дамп PS5 (`eboot` + `sce_module/*.prx`) несёт в себе копии системных
библиотек **того SDK/прошивки, на которых игра собрана**. Значит, игра,
смастеренная после октября 2026 на прошивке 14.2x, может содержать модули
14.2x-эпохи — то есть быть ближайшим к «дампу 14.22», что реально может
существовать.

Проверяем: (1) есть ли свежие дампы ≥ осени 2026; (2) какие в них модули;
(3) если найдётся — сравнить с нашим дампом Cyberpunk 02.120.

## 1. Наш дамп: что именно в нём лежит (исходная точка, подтверждено)

Каталог: `games/cyberpunk/anyps5-run/sce_module/`

```
libc.prx                   1 352 554
libSceFace.prx               342 144
libSceFaceTracker.prx      2 644 167
libSceJobManager.prx         113 062
libSceNpCppWebApi.prx      7 491 911
libScePfs.prx              1 381 071
```

`PT_SCE_COMMENT` (тип `0x6fffff00`) каждого модуля содержит **путь сборки Sony** —
главный маркер возраста, по нему и будем сравнивать дампы:

```
libc.prx      W:/Build/J01625764/sys/internal/usermode/src/libc/Prospero_Release/libc.prx
libScePfs.prx W:/Build/J01625764/sys/internal/usermode/src/libpfss/Prospero_Release/libScePfs.prx
```

(полные hex-дампы — ниже, в приложении; команда: `python3 -` с разбором PHDR,
см. `ps5jb/recon/_src/gen_vs.py` при необходимости воспроизвести)

Вывод: маркер `J01625764` — идентификатор сборки Sony; у свежего дампа он
должен быть другим (более новым), и/или появится другой набор модулей.
